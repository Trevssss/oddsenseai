DATA & ACCURACY

Clear about what OddSense can—and can’t—know.

Sports outcomes are uncertain. Historical form and statistics can be incomplete or misleading; no AI or model can guarantee a correct pick or a profit.

✓

Live football fixtures require a GOAL API key. The key is read by the local server and is not included in browser code.

✓

Sport coverage depends on your API products and plan. Additional sports need an available product endpoint and compatible adapter.

✓

Analysis uses historical indicators. Team statistics, head-to-head, and lineups appear only when GOAL API provides them; a displayed lean is not a calibrated probability.

✓

Final-result feedback is score-based. OddSense only marks a selection won or lost after a provider reports a verified final score.

YOUR PICKS, YOUR DECISION

A clearer slip.
No fake booking codes.

SportyBet, Bet9ja and MSport do not share one universal booking-code format. OddSense prepares a manual-entry summary; it does not place bets or claim that a generated code will work.
